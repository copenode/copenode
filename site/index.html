copenode

01 / the system

Gravity for your agent swarm.

copenode is the policy spine beneath your agent nodes — gateways, coding-agent fleets, schedulers, sandboxes. It answers the four questions that decide whether autonomy is safe to grant: who asked, what may they reach, how much may it cost, and how bad can it get.

02 / doctrine

Five laws, written day one.

Copernicus didn't command the planets — he chose a center that made their motion coherent. copenode is that chosen center for agent systems.

01

Autonomy is the goal.

Planets carry their own momentum. Agents should act without waiting for you.

02

Stability is what buys it.

An orbit is not a cage — it is what makes motion coherent instead of chaotic. Every grant of autonomy ships with a systemic bound.

03

Trust is tiered, not binary.

owner → worktree. sender → sandbox. system → contained. Prompts you didn't type never run unsandboxed.

04

Every action is metered.

An ephemeris, not just a bill: each ledger entry carries what it cost, a trail of what happened and why, and evals of how well it went. One spine, three lenses.

05

Nodes stay sovereign.

The sun does not consume the planets. copenode orchestrates nodes; it does not replace them. Adapters, not forks.

03 / the first orbit

A message becomes an agent. The diff returns to the thread.

The first integration bridges openclaw — the open-source assistant living in your chat channels — with paseo, the environment that runs coding agents in parallel git worktrees on your machines.

04 / packages

Thin packages around a light core.

@copenode/core shipped bridge protocol · metering ledger · trust-tier policy engine npm i @copenode/core
copenode shipped meta package — reserves the name, points to the code npm i copenode
@copenode/cli shipped copenode trail / copenode verify — read the ledger, check the chain npm i @copenode/cli
copenode/paseo-plugin building daemon-side: workspace lifecycle, sandbox hooks, usage events paseo plugin add copenode/paseo-plugin
@copenode/openclaw-plugin building gateway-side: channel tools, approval cards, diff rendering openclaw plugin install @copenode/openclaw-plugin

credentials never move — each daemon keeps its own keys; sandboxed agents get short-lived, task-scoped ones.
