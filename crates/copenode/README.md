# copenode

**Architectural foundation and node orchestration platform.**
**Autonomy engineered around systemic stability.**

This crate reserves the Rust name for the copenode project. The active code
lives in the TypeScript monorepo:

- [`@copenode/core`](https://www.npmjs.com/package/@copenode/core) — identity
  mapping, trust-tier routing, the metering ledger
- Repository: [github.com/copenode/copenode](https://github.com/copenode/copenode)
- Web: [copenode.com](https://copenode.com)

Rust nodes and protocol taps will live here when the platform's protocol lane
needs them.
