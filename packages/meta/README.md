# copenode

**Architectural foundation and node orchestration platform.**
**Autonomy engineered around systemic stability.**

copenode is the policy spine beneath heterogeneous agent nodes — assistant
gateways, coding-agent fleets, schedulers, sandboxes. Nodes declare identity,
trust, and budget; copenode routes work to them, meters every action, and
contains every blast radius.

This meta package reserves the name and points to the real code:

- **[`@copenode/core`](https://www.npmjs.com/package/@copenode/core)** —
  identity mapping, trust-tier routing policy, metering ledger
- **`@copenode/paseo-plugin`** *(coming)* — daemon-side plugin (first integration:
  the [OpenClaw](https://github.com/openclaw/openclaw) ↔
  [Paseo](https://github.com/getpaseo/paseo) bridge)
- **`@copenode/openclaw-plugin`** *(coming)* — gateway-side plugin
