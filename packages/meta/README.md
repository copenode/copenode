# copenode

**Chat in. Agents out.** — meta package.

`copenode` connects [OpenClaw](https://github.com/openclaw/openclaw) (the
open-source assistant living in your WhatsApp, Telegram, and Discord) to
[Paseo](https://github.com/getpaseo/paseo) (the open-source environment that
runs Claude Code, Codex, and OpenCode in parallel git worktrees).

This package exists to reserve the name and point you to the real code:

- **[`@copenode/core`](https://www.npmjs.com/package/@copenode/core)** —
  shared bridge protocol, identity mapping, metering, routing policy
- **`@copenode/paseo-plugin`** *(coming)* — daemon-side plugin
- **`@copenode/openclaw-plugin`** *(coming)* — gateway-side plugin
